我怎么在本地启动前后台，确认dashboard

**本地启动（推荐：前后端分别启动）**

**1）启动后端（FastAPI）**
- 在项目根目录执行：

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
alembic -c backend/alembic.ini upgrade head
uvicorn app.main:app --reload --app-dir backend
```

- 验证后端是否起来：
  - Swagger：`http://localhost:8000/docs`
  - Dashboard API（需要登录 token）：`GET http://localhost:8000/api/v1/dashboard/overview`

**2）启动前端（Next.js）**
- 新开一个终端，在项目根目录执行：

```bash
cd frontend
cp .env.example .env.local
npm install
npm run dev
```

- 打开前端：
  - 首页：`http://localhost:3000/`
  - Dashboard：`http://localhost:3000/dashboard`

---

**如何拿到 token（给 Dashboard 用）**
- 在 Swagger 里走注册/登录（最简单）：
  1. 打开 `http://localhost:8000/docs`
  2. 调用 `POST /auth/register`（或 `POST /auth/login`）
  3. 响应里会有 `access_token`
- 把 `access_token` 粘贴到前端 Dashboard 页面的 “Access token” 输入框，点 `Save`，再点 `Load`。

---

**快速自检清单（确保 Dashboard 有数据）**
- 先在 Dashboard 里能 `Load` 成功，看到 counts 不为 0（至少 `hitl_requests/mcp_tool_calls/...` 可能为 0 属于正常）
- 如果想快速制造数据：
  - 调用一次 `POST /agents/runs`
  - 或上传一次 `POST /rag/upload`
  - 或注册一个 MCP server 并调用一次 tool（并可触发 HITL pending）

---

**常见问题**
- 前端请求不到后端：确认 `frontend/.env.local` 里 `NEXT_PUBLIC_API_BASE_URL=http://localhost:8000`，改完需重启 `npm run dev`
- `Load` 返回 401：token 过期或粘贴了 refresh_token；请用 `access_token`
- 迁移失败/表缺失：重新跑 `alembic -c backend/alembic.ini upgrade head`
