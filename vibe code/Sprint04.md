- 连接：`ws://localhost:8000/ws?token=<access_token>`（或 `/api/v1/ws`）

- 服务端推送事件：`connected` → `thinking` → 多个 `token` → `completed`
- 流式输出同时会把 user/assistant 两条消息写入数据库
